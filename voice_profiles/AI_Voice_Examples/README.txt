AI Voice Examples — Original Profiles

This package contains four ORIGINAL voice profiles inspired only by broad character traits.
They are not recordings or clones of the actors or copyrighted character performances.

Folders:
- JARVIS_inspired
- FRIDAY_inspired
- TONY_inspired
- ULTRON_inspired

Each folder contains:
- profile.txt: voice direction and characteristics
- sample.txt: short sample dialogue
- tts_prompt.txt: prompt suitable for a text-to-speech system
